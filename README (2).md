## عن المشروع | About

موقع تفاعلي من صفحة واحدة (HTML / CSS / JavaScript) على شكل لعبة استكشاف. يدخل الزائر الغابة، يتعرّف على صاحبة الموقع، ثم يمرّ بمحطات على خريطة متحركة، ويجمع كنزًا في كل محطة حتى يصل إلى **الكنز الكبير: إتقان مسار الويب**.

## الرحلة | The Journey

1. **شاشة البداية:** اختيار المستكشف ثم دخول الغابة.
2. **About Me:** صفحة واحدة تجمع التخصص والاهتمامات والمعرفة (بطاقات فلاش تنقلب بالضغط) والمشاريع قيد الإنشاء والطموح.
3. **الخريطة:** بعد كل محطة يمشي مسار متحرك على الخريطة إلى المحطة التالية.
4. **المحطات:** Web in My Words، The Code Lab (HTML / CSS / JavaScript)، Frontend & Backend.
5. **النهاية:** رسالة شكر مع الخريطة كاملة، ثم يترك المستكشف اسمه وصورته وأمنيته، ويرجع الموقع تلقائيًا للبداية.

## المميزات | Features

- نظام تقدّم: كنوز، مستوى (XP)، حقيبة كنوز، وإنجازات.
- مسار متحرك على الخريطة بين المحطات.
- أمثلة تفاعلية: محرّر HTML مباشر، تغيير ألوان CSS، زر JavaScript، ومحاكاة لطلب المتصفح والخادم.
- ثيم ليلي / نهاري.
- أصوات طبيعية وسحرية (رنين وحفيف أوراق) مولّدة بـ Web Audio API، مع زر كتم.
- أيقونات SVG مصممة خصيصًا للواجهة.
- بطاقة المستكشف: اسم وصورة وأمنية تُحفظ في المتصفح (`localStorage`).
- متجاوب ويعمل بشكل ممتاز على الجوال، ويدعم العربية (RTL) والإنجليزية.

## التقنيات | Tech

`HTML5` · `CSS3` · `JavaScript (Vanilla)` · `SVG` · `Web Audio API` · `localStorage`

بدون مكتبات أو أطر عمل. الصور مضمّنة داخل الملف نفسه (Base64)، لذلك الموقع كله في ملف واحد.

## التشغيل والنشر | Run & Deploy

**محليًا:** افتحي `index.html` في أي متصفح.

**على GitHub Pages:**
1. ارفعي `index.html` و`README.md` إلى المستودع.
2. من **Settings → Pages**، اختاري Branch: `main` والمجلد `/ (root)`.
3. احفظي، وبعد دقائق يصير الموقع متاحًا على الرابط أعلاه.
